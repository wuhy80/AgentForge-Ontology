# 本体全景：本体目录、关系与依赖可视化

状态：2026-11-08 已实现首批只读本体浏览入口，并完成单元、隔离浏览器和构建验证。入口位于工作台“工作空间”下方，路由为 `#ontology`。本页维护跨模块的浏览体验；五类定义规则、分类隔离和授权规则仍以所属模块及[组织与隔离](组织与隔离.md)、[权限主说明](权限/权限设计.md)为准。

本轮参考了 [Palantir Ontology Manager 官方概览](https://www.palantir.com/docs/foundry/ontology-manager/overview/)中的资源发现、结构浏览和详情联动。实例关系图、画布建模编辑、动态源码调用链、数据血缘、全局实例计数和发布差异图仍属于后续范围。

## 1. 入口与范围

侧栏“工作台”分组按“工作空间”“本体全景”顺序显示新入口。页面沿用顶栏当前分类，不创建第二个分类上下文；跳转到其他分类的定义或数据探索时，先更新顶栏分类，再进入目标页面。

页面只读取当前生效定义。草稿仍由既有定义页查看和维护，本页不读取草稿目录，也不显示“存在草稿”徽标。没有可访问分类时不请求目录；分类切换、刷新、401/403 和迟到响应都会清理旧目录、详情、画布及对应个人布局。

## 2. 目录加载

目录展示对象模型（Schema）、关系（Link）、枚举（Enum）、动作（Action）和函数（Function）五类资源，支持中文名称/说明搜索、类型筛选和分组筛选。目录数据通过现有定义分页接口读取 `view=current`，加载器校验租户、分类、类型、稳定 ID 和 `active` 状态，不把草稿或其他租户记录混入当前范围；分组读取失败时保留定义并显示通用提示。

主目录完成后只补齐定义中的直接稳定引用，最多 120 个目标、并发 4，不递归读取依赖。目标无权访问或不存在时只显示通用不可查看提示；401 终止本次加载，403/404 不暴露目标名称或后端错误文本。跨分类引用只有在目标分类和定义均可访问时才进入图和详情。

## 3. 两类只读画布

### 对象关系图

Schema 为节点、Link 为连线，展示中文正反名称和基数，支持自关联和平行 Link。目录选择会定位对应节点或 Link 端点；单击节点/连线打开详情，双击节点聚焦并可展开当前范围。图使用稳定 ID，复用既有关系建图、校验和布局 helper，但使用独立的只读 ReactFlow 画布，不提供拖线创建、删除或编辑。

### 定义依赖图

五类资源均可作为节点，连线只来自协议中的稳定引用：Schema 属性的 Enum、Action 的作用对象和绑定 Function、Function/Action 参数和输出中的 Enum，以及 Link 的 source/destination 对象。引用边使用虚线并标注引用含义；不根据名称相似、源码文本或动态调用推断依赖。选择 Enum、Action 或 Function 时自动切换到依赖图，手动切换模式会清除聚焦状态。

两类画布都接收完整授权目录和当前筛选根节点。筛选不会删除未显示但仍有授权的布局；依赖图会补入可见根节点的反向引用来源。单次画布最多 120 个节点、240 条边，选择对象优先保留，超出时显示截断提示，不把预算结果表述为完整租户图。

## 4. 详情与操作

右侧详情按资源类型展示业务说明、分类/分组、属性或参数、枚举成员、Link 正反方向与基数、来源概要、引用和被引用。详情重新按当前授权目录解析稳定 ID，旧响应或撤权后不会继续显示旧资源；缺少引用目标时只显示通用不可查看说明，不暴露来源 ID、源码、凭据或物理连接细节。

“查看定义”进入现有五类定义页，沿用原编辑、草稿和生效权限；Schema 的“查看数据”进入数据探索，仍需用户显式运行查询。本体全景本身不读取业务实例、不执行 Action/Function，也不发起写入请求。

## 5. 布局与个人偏好

桌面端使用目录、画布、详情三栏布局；宽度不足时详情移到下方，宽度不超过 720px 时使用已有 Dialog 显示详情，并提供“在画布中聚焦”。目录和画布可切换，画布提供缩放、适配、自动布局、重置和邻居展开。

布局只保存稳定 ID 的坐标和 viewport，按租户、账号、分类及画布模式隔离，键格式为 `agentforge:ontology-layout:<tenant>:<user>:<category>:<mode>`。改名保持布局和选中身份，同名新建的定义不会接管旧位置；刷新或授权失效会裁剪无效 ID。布局偏好只保存在浏览器本地，不保存定义内容、会话凭据或查询结果。
