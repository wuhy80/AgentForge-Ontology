# 文档术语表

这些术语是工程手段，不是额外的 Ontology 业务对象。文档优先用直接说明，确有需要时再引入术语。

| 术语 | 通俗解释 | 本项目例子 |
| --- | --- | --- |
| 探针 | 检查服务状态的小接口或程序 | 检查服务是否存活、是否可以接收请求 |
| 快照 | 某个时间点的数据副本 | 读取一次源库目录供预览比较；不表示可选择执行的历史定义，也不自动等同于数据库备份 |
| 证据 | 支持判断的可检查记录或数据 | 查询结果、执行日志、迁移验证记录 |
| 门禁 | 满足条件才能进入下一步骤的检查 | 模型校验失败时阻止发布 |
| 夹具 | 测试用的预置数据或环境 | 固定的设备、产线和关系样例 |
| 哈希 | 按算法从内容计算出的摘要 | 校验代码制品或迁移文件是否变化；哈希本身不是加密或身份认证 |
| 冒烟测试 | 快速检查最基本流程是否可用 | 启动后创建一个模型、写入并查询一条数据 |
| 基线 | 用于比较变化的参照状态或指标 | 同一批查询在固定环境中的延迟记录 |
