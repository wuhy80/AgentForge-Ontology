# 权限

本目录集中维护 Ontology 权限设计、开源引擎调研、选型依据和验证资料。首批已将 OPA 接入 Metadata/Data，并完成真实 MySQL/OPA 的受限行列权限验证；完整权限目标、独立引擎实验与当前交付边界分别在[权限设计](权限设计.md)标记。

2026-11-07已按用户确认补齐本地账号密码登录、可撤销服务端会话、用户创建/启停/密码管理、角色分配、中文权限策略草稿/模拟/生效及管理审计，随后补齐[用户组与有效角色](权限设计.md#用户组与有效角色)。当前边界见[用户管理要求与实现缺口](权限设计.md#用户管理要求与实现缺口2026-11-07)，实际接口见[身份与权限模块](../../services/metadata/identity/README.md)。

[权限设计](权限设计.md)是公共权限机制的唯一主要说明。当前选择为OPA 1.21.2 + Ontology自有权限配置与执行层；首批开放受限结构化决策与同字段集合的安全规则合并，不能安全表示的直接或组继承角色组合明确拒绝。组嵌套、外部目录、通用UCAST、任意多角色字段组合、调用授权及跨服务原子撤权仍待后续实现或认证。

后续权限专题与验证资料统一存放在本目录，各主题只维护一份主要说明。其他模块引用权限规则，并维护各自落实授权的执行边界；租户组织、查询语义及任务编排分别见[组织与隔离](../组织与隔离.md)、[DataSet](../数据查询/DataSet.md)和[执行与调度](../执行与调度.md)。
