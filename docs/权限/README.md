# 权限

本目录集中维护 Ontology 权限设计、开源引擎调研、选型依据和验证资料。首批已将 OPA 接入 Metadata/Data，并完成真实 MySQL/OPA 的受限行列权限验证；完整权限目标、独立引擎实验与当前交付边界分别在[权限设计](权限设计.md)标记。

| 文档或资料 | 维护内容 |
| --- | --- |
| [权限设计与开源方案调研](权限设计.md) | 行列过滤、读写与 Action/Function 限制、策略配置、执行身份、撤权、引擎比较和选型理由，以及 AUTH-01～AUTH-14 验收计划 |
| [验证资料](验证资料/README.md) | 原始验证包、归档校验信息、实验范围及复查入口 |

[权限设计](权限设计.md)是公共权限机制的唯一主要说明。当前选择为 OPA 1.21.2 + Ontology 自有权限配置与执行层；首批只开放受限结构化决策，通用 UCAST、多角色合并、调用授权及原子撤权仍待后续实现或认证。

后续权限专题与验证资料统一存放在本目录，各主题只维护一份主要说明。其他模块引用权限规则，并维护各自落实授权的执行边界；租户组织、查询语义及任务编排分别见[组织与隔离](../组织与隔离.md)、[DataSet](../数据查询/DataSet.md)和[执行与调度](../执行与调度.md)。
