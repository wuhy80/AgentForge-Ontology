# 工作台视觉升级

状态：2026-11-08 用户预览后确认两套主题都支持，正式工作台已接入「深空蓝」和「精密白」。本文件统一维护视觉规则、主题偏好及覆盖范围；验证结果见[项目总览](项目总览.md#工作台双主题2026-11-08已实现)。下方独立原型仍使用示例内容，与正式页面和业务数据区分。

## 目标与问题

原界面以浅绿/米白、大面积留白及相近的圆角卡片构成，图、目录和详情的视觉层次不足。本次升级保留现有中文导航与功能，通过明确的背景层级、紧凑工作区、清晰的排版和有含义的状态色表达本体管理产品的科技感。

本体关系图作为视觉重点，其他区域克制处理。不采用装饰性大屏数字、无业务含义的科幻仪表、持续粒子动画或全屏霓虹光效；示例中的定义数量、名称和查询结果不表示真实租户数据。

布局采用固定导航、窄顶栏、标题与筛选、定义统计条，以及目录/画布/详情工作区。画布有轻量网格和有限的选中高亮，连线按业务关系和依赖分别表达；查询页沿用相同框架，代码编辑与结果区域保持各自清晰的阅读层级。

## 正式主题与偏好

登录页右上方、工作台顶栏均提供两个主题按钮，带当前选中状态和键盘焦点。首次使用默认深空蓝，用户可切换精密白。窄屏工作台保留主题名称，登录页的图标按钮保留可访问名称。

偏好以 `agentforge.theme` 保存于当前浏览器来源的 localStorage；同源标签页同步，刷新、退出登录和重新登录均保留。4173与5173属于不同来源，各自保存；偏好不随账号同步。清除偏好或值无效时回到深空蓝。存储不可用时仍允许当前页面切换，刷新后无法记住。HTML首帧在React挂载前读取偏好，并同步浏览器原生控件的 `color-scheme` 和主题色。

正式语义令牌集中在[theme.css](../apps/web/src/theme.css)，扩展原有 `--ink`、`--muted`、`--line` 与容器圆角等规则；原绿色主色迁移为 `--primary`。页面、导航、表面、画布、编辑器、文字、边框、五类定义、成功/警告/错误各有语义角色。深色主按钮使用较深的钴蓝填充与白字，链接/选中标签使用较亮的蓝色；两者分开以保证可读性，不直接将原型中所有蓝色都用作按钮背景。

正式覆盖登录、概览、五类定义列表/表单/关系画布、分类分组、SQL与可视化查询、数据源管理与来源SQL、用户权限、外部连接与授权页面，以及共用表格、对话框、空态、提示、禁用和焦点样式。本体全景使用横向五类统计区、目录/画布/详情布局和青色关系强调；页面容器主要采用7px圆角，表单与小控件更紧凑，辅助文字不低于11px。

OntologySQL、来源SQL与Python/JavaScript/Go源码编辑器共用语法令牌，行号、选区、光标、补全提示、诊断和活动行随主题变化。切换通过CSS变量更新现有编辑器，不重新创建实例，保留未保存内容、选区和撤销历史。ReactFlow连线、箭头及网格也使用同一组令牌；主题选择不会提交定义或执行查询。

查询与本体全景的目录、搜索样式按各自页面限制作用范围，避免先访问查询后本体目录被覆盖。已有目录、权限、查询、编辑、保存/生效和执行协议继续沿用；本次没有后端协议、数据库迁移或业务数据变更。视觉复核、隔离浏览器交互和已有单元回归分别记录，不将示例截图或模拟接口当作真实业务验收。
