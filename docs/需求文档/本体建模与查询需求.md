# 本体建模与查询需求

状态：需求草案。承接已有基础语义讨论；建议边界和待定范围仍需在接口设计中确认，本文不是已实现功能清单。

## 1. 核心对象

| 对象 | 职责 | 需要表达的内容 |
| --- | --- | --- |
| Schema | 定义实体及属性 | 字段类型、约束、标识、版本 |
| Enum | 定义可用取值 | 稳定值、显示名称、引用、废弃规则 |
| Link | 定义实体之间的关系 | 端点、方向、基数、查询路径 |
| Function | 提供可调用计算 | 输入输出、语言、实现版本、运行要求 |
| Action | 表达业务操作 | 参数、目标、效果、权限、执行状态关联 |

五类对象是业务建模概念。模块的职责与依赖见 [模块化与演进需求](模块化与演进需求.md)；实例与关系数据由 Data 服务管理，执行状态由 Execution 服务管理。首期不要求完整 OWL/RDF 推理体系。

## 2. Schema 与 Enum

Schema 需要覆盖常见数据库类型，并描述主键、业务唯一键、可空性、必填、默认值、校验条件和索引。类型必须区分整数范围、数值精度、时间语义，以及 `false`、`null` 和字段缺失。适配器明确标注原生支持、转换支持或不支持，不能静默截断、丢失精度或改变语义。

HTTP/JSON 接口需要定义 int64、decimal、时间和二进制的无损表示。数组、空间类型和其他数据库专有类型按能力扩展；首批逻辑类型及物理映射方案见 [数据与查询设计](../设计文档/数据与查询设计.md)。逻辑 Schema 不必与物理表一一对应，模型变更是否产生 DDL 由存储方案决定。

Enum 可被字段及调用参数引用，参与版本管理与校验。建议使用稳定值编码和可修改的显示名称；增加、删除、重命名和废弃取值分别评估兼容性。删除仍被实例或参数定义引用的取值前，需要完成数据和引用处理。数据库原生 ENUM 是否适用属于存储选型。

## 3. Link 与查询语义

支持正向 `out`、反向 `in`、双向 `both` 查询，以及多级路径和关联过滤。关系定义应描述名称、两端 Schema、正反向名称、1:1／1:N／N:M 基数、重复边规则和删除行为。

例如：`工单 --使用设备--> 设备 --所属产线--> 产线 --所属车间--> 车间`。既可以从工单查车间，也可以沿反向关系查某车间内的相关工单。

查询协议需要区分固定路径和不定长遍历，明确路径端点、每层过滤、去重、分页以及返回实体、关系或路径的方式。限制最大跳数、扫描量、结果数与执行时间，防止关系分支导致路径数量膨胀。四跳是候选测试范围，尚未确定为产品上限。

首期建议实现有界固定路径；不定长遍历、可达性、最短路径及图算法是否进入首期仍待确认，不能因支持 Link 就宣称支持全部图查询能力。存储方案与数据库能力比较见 [数据与查询设计](../设计文档/数据与查询设计.md)，性能条件统一见 [性能与容量需求](性能与容量需求.md)。

## 4. Action 与 Function

两者均需要支持多语言实现，并可同步或异步调用。建议 Function 默认用于查询与计算，Action 表达具有业务效果的操作并可调用 Function；读写权限、外部副作用和重试条件必须显式声明，不能仅靠名称判断。

定义需要关联输入输出、语言运行要求、实现版本和制品。Go 作为平台服务实现方向不限制用户函数语言；首期运行器可以从一种语言起步，其他语言通过一致的运行器契约扩展。调用语义及执行隔离见 [执行与触发需求](执行与触发需求.md)，具体实现方式见 [执行与调度设计](../设计文档/执行与调度设计.md)。

## 5. 需求与验收

| 编号 | 要求 | 验收方法 |
| --- | --- | --- |
| CORE-01 | Schema 描述类型、标识和字段约束，实例读写遵循指定版本 | 验证必填、可空、唯一键、默认值和非空约束，错误输入有明确原因 |
| CORE-02 | 类型映射和传输不丢失语义，适配能力可查询 | 覆盖边界整数、decimal 精度、时区、二进制以及 false/null/缺失的往返校验；不支持的类型明确拒绝 |
| CORE-03 | Enum 可被字段和调用参数引用，变更兼容性可判断 | 验证非法值拒绝、稳定值与显示名称分离，以及删除使用中取值的处理 |
| CORE-04 | Link 明确端点、方向、基数、重复与删除规则 | 多对多样例正反向结果一致；违反基数、重复边或删除规则时按约定处理 |
| CORE-05 | 多级查询明确过滤、去重、分页和执行预算 | 对固定路径逐层核对结果；高分支、循环和超预算请求可控结束 |
| CORE-06 | Action/Function 定义关联版本、输入输出和执行要求，并声明副作用 | 定义可注册校验，调用能追溯制品和版本；新增语言可遵循运行器契约接入 |

## 6. 待定事项

首个数据库及版本、是否必须兼容 MySQL/达梦、是否跨源读写、物理存储模型、首期路径能力及跳数限制、首批语言、Action/Function 权限与事务边界、对外查询协议和身份隔离方式均需继续细化。
