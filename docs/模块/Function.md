# Function：可调用计算与运行定义

状态：完整设计与首批实现并行维护。用户于2026-11-07确认先实现Python运行器，随后扩展JavaScript，Go等通过容器或外部服务接入。Metadata定义维护、首批Python纯计算执行及中文工作台已实现，验证范围统一见[项目总览](../项目总览.md#当前实现与验证2026-11-06)。本文维护源码、运行器及类型协议；任务和权限分别引用所属专题。

## 1. 用途与边界

Function 提供可调用的查询、计算或外部能力。建议默认用于查询与计算；读写权限及外部副作用必须显式声明，不能因为名称是 Function 就认定只读、确定性或可安全重试。

Metadata 的 function 模块保存一份当前定义、输入输出及实现引用，不设置业务 version。Execution 管理调用与任务，Worker 执行代码。具有业务效果的操作可由 [Action](Action.md) 组织并引用 Function；平台采用 Go 不限制函数实现语言。

组织归属及中文名称解析规则见 [组织与隔离](../组织与隔离.md)。用户按中文 name 维护和选择 Function、Schema 和 Enum，内部定义引用使用稳定 ID；输入输出按中文参数名编辑，再映射已声明的运行器参数键。运行身份、制品读取及数据访问固定在已验证的租户上下文内，下文内部清单不要求用户手填 ID。

## 2. 定义与运行清单

### 首批Python运行协议（2026-11-07已实现）

实际类型见[运行契约](../../contracts/execution.go)。Function正文增加可选`runtime`：`language`固定`python`，`source`为不超过64 KiB的UTF-8源码，`entrypoint`为普通Python函数名（默认示例`main`），`timeoutSeconds`为1～30秒。未配置runtime的既有定义继续可以登记；登记不表示可调用。当前只开放`sideEffects=none`，不支持第三方依赖安装、文件制品加载、用户指定镜像、联网访问或平台数据读写；其他语言及副作用声明在调用时明确拒绝。内联源码与`artifactRef`不能同时配置。

输入和输出各最多256个参数，支持string、text、longtext、uuid、int64、decimal、boolean及timestamp标量，不支持Enum引用、存储映射或复杂对象/数组参数。每次输入和输出分别受256 KiB总预算约束，不能将单字段longtext上限理解为本接口的请求预算。

源码作为当前定义的一部分，经草稿和发布更新；不要求修改或重新编译平台Go服务。已生效Function允许更新runtime源码、入口和超时，输入输出签名、副作用和实现引用继续沿原结构变更限制。发布后新调用使用新实现，已开始调用保持本次源码快照；历史结果与当前定义不兼容时拒绝读取，具体规则见[执行与调度](../执行与调度.md)。源码与当前定义仍各只有一份，不新增业务version或旧定义选择入口。

入口接收并返回字典，键使用当前定义声明的中文参数名。HTTP输入和输出仍用稳定属性ID，由Execution按本次定义快照映射，用户不填写ID。未声明键、类型不符、缺少必填值或非法空值明确失败；int64、decimal仍以字符串无损传输，代码需自行使用`int`或标准库`decimal.Decimal`计算并转换回字符串。参数中文名变更不会自动改写Python源码中的字符串引用，作者须同步检查源码；已有绑定Action时还须保持双方签名一致。以下为用户代码示例：

```python
def main(inputs):
    return {"字符数": str(len(inputs["正文"]))}
```

运行器使用部署方配置的Python 3.12镜像，启动时解析为实际本地镜像ID后执行；请求不能指定镜像、Docker参数或宿主命令。每次调用使用独立容器、非root用户、只读根文件系统和有限临时目录，关闭网络、移除Linux capabilities，限制CPU、内存、进程数及时间；不挂载宿主目录，不传入平台数据库或服务凭据，不降级到宿主Python。容器限制属于本地开发与受控代码的首批隔离措施，不据此认证恶意多租户代码沙盒或生产隔离。

标准输出、标准错误和异常堆栈不作为公共结果返回；只接受受限JSON输出并按声明类型再次校验。容器中的Python print不构成业务结果。代码摘要、实际镜像ID和本次定义快照由Execution保存用于核对；结果、重试和清理规则以[执行与调度](../执行与调度.md)为准。工作台提供源码、参数表单和当前生效定义的运行入口；未发布草稿不能运行。

### 完整运行清单候选

| 内容 | 需要说明的行为 |
| --- | --- |
| id、tenantId、categoryId、groupId | 稳定标识及组织归属 |
| name、labels、description | 主展示名及说明 |
| input、output | 类型、必填、约束、Enum 引用及计量单位 |
| runtime、entrypoint | 运行方式、语言/运行时版本、入口 |
| artifactRef、运行依赖 | 当前代码制品摘要与实际执行环境，能关联到运行记录 |
| timeout、resources | 超时及 CPU、内存等资源要求 |
| permissions、sideEffects | 按[权限设计](../权限/权限设计.md)声明能力要求/策略绑定；说明数据范围、外部系统写入及可重试条件，不作为独立允许名单 |

输入输出复用 [Schema](Schema.md) 的属性语义和 [Enum](Enum.md) 引用。计量参数采用受控单位及明确转换规则，不能将单位不同的裸数直接传入计算。多语言调用同样需要 int64、decimal、时间、二进制的无损表示。

Schema 计算属性的轻量公式使用受限表达式，由 Data 查询/写入计划批量执行；计算策略及依赖规则见 [Schema](Schema.md)。复杂计算可显式引用纯 Function 用于后台物化，但不能在 Data 的查询中按每行远程调用 Function，也不能在同步写事务中运行任意脚本。可物化函数的输入依赖、权限范围及确定性必须可验证，更新实现时检查并失效所有依赖结果；外部数据、当前时间及随机结果不能伪装成仅由声明字段决定的值。

制品引用在生效时需解析到确定的代码内容及依赖，任务开始时记录实际摘要。更新代码后修改当前 artifactRef，新开始的任务使用新实现，已开始任务不更换制品；摘要用于定位字节内容，不成为 Function 定义版本或旧定义调用入口。示例中的 Python 运行时版本仍需保留，是执行环境信息，不是业务 version。副作用声明需要配合实际权限和隔离措施执行。

用户按“电压”“电流”填写并读取“功率”，示例 voltage/current/power 只表达内部运行器适配键；输入、输出各自在自身范围校验中文参数名唯一，代码入口 power:calculate 保持实际制品约定，不要求改成中文函数名。

## 3. 多语言实现建议

| 方式 | 执行方式 |
| --- | --- |
| 脚本包 | Python、JavaScript 等运行器按内容摘要加载代码及锁定的依赖 |
| 容器 | 按约定入口与协议执行 Go 等编译语言或带专有依赖的实现 |
| 外部服务 | 通过 HTTP/gRPC 调用已有计算服务 |

首批已确认优先Python；本节脚本包分发、自定义容器、外部服务及JavaScript均为后续扩展，不表示当前接口已接收这些实现。制品按内容摘要分发与缓存，依赖固定到可核对内容；大输入、输出可使用存储引用，保证执行记录仍能定位内容及保留期限。

运行器按代码可信程度限制 CPU、内存、执行时间、文件和网络权限，业务凭据按调用身份提供，任务工作目录相互隔离。容器本身不等于完整沙盒。具体资源、租约、故障恢复和任务隔离验收见 [执行与调度](../执行与调度.md)。

## 4. 调用流程与接口边界

直接 invoke、仅供指定 Action 内部调用、原调用者/运行身份及输入输出权限的候选规则统一见[权限设计](../权限/权限设计.md)第 7 节。获准调用不自动授予函数全部数据访问能力，sideEffects 声明也不替代受限凭据和实际隔离；相关后续验收引用 AUTH-04、AUTH-07～AUTH-09、AUTH-14。

建议流程：按中文名称选择并绑定 ID → 按 ID 读取当前定义 → 验证调用权限和输入类型/单位 → 提交任务 → 实际开始时解析当前定义及依赖并重新校验 → 保存本次执行内容及制品摘要 → 运行、校验输出并保存结果。已绑定调用沿用原 ID 并检查当前状态，不按旧中文文本重新选取同名定义。

Function 与 Action 都支持同步和异步调用，共用权限、任务及重试语义。同步等待预算不以 100 ms 为统一分界；客户端超时并不自动取消计算。限时等待、结果轮询、通知、取消与错误状态统一见 [执行与调度](../执行与调度.md)，本模块不再维护另一套任务状态机。

定义模块提供注册/编辑草稿、读取当前定义、检查依赖及清单、变更影响分析能力；调用与任务查询由 Execution 的公共接口提供。新增运行器不应修改 Data 查询模块，新增计算函数不应修改通用 API 入口中的类型分支。

## 5. 当前定义、实现更新与依赖

Function、Action 及输入输出引用的 Schema/Enum 均按稳定 ID 解析当前定义，不维护版本发布集。运行时和依赖软件版本仍作为环境信息保存，制品用内容摘要定位。每次更新替换当前函数定义，检查所有 Action 引用、订阅、周期规则及参数约束。

排队任务启动时取最新定义并重新校验，已开始任务和重试沿用本次记录的执行内容；不兼容变更先排空相关运行任务，不能用旧任务上下文绕过 Data 当前规则。改变输入单位、必填参数、返回类型、默认值行为或副作用时检查调用方。缓存结果是否成立取决于输入、当前实现及数据状态、外部依赖和确定性，不能默认所有 Function 都可缓存；定义变化后不得命中旧实现的缓存。共同流程见 [发布与迁移](../发布与迁移.md)。
