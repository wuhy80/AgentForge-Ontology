# 数据查询

本目录集中维护 Ontology 数据查询设计与实际协议。已实现中文 QuerySpec 查询、行列授权、签名游标及同源 Link 单跳正反导航，具体边界见 [DataSet](DataSet.md)。用户于2026-11-07确认开发 `#query` 的OntologySQL默认模式、使用指导和自动补全；首批单Schema文本编译到同一QuerySpec，实际接口见[OntologySQL](OntologySQL.md#首批实际协议2026-11-07)，界面见[可视化查询编辑器](可视化查询编辑器.md)。已新增最多4条INNER Link关联行、授权最短路径候选和多别名字段插入；统计、复杂关系及跨源执行仍按共享计划分期。

| 文档 | 维护内容 |
| --- | --- |
| [DataSet](DataSet.md) | 中文 Schema/属性/Link 名称编写及 ID 绑定、查询抽象、条件筛选、字段投影、关系导航、多 Link 跳转、聚合、结果与分页、预览及查询验收 |
| [OntologySQL](OntologySQL.md) | 中文本体文本、首批可降低到现有QuerySpec的语法与参数/诊断/补全实际协议、Link分期及文本入口验收 |
| [可视化查询编辑器](可视化查询编辑器.md) | SQL/可视化同页工作台、模型目录/模板/步骤指导、上下文补全与参数交互、中文条件/关系编辑、组件及体验验收 |

DataSet 是共同查询语义与执行规则的唯一主要说明，OntologySQL 维护文本语法与编译，可视化编辑器维护交互与编辑状态；建议各入口共用 QuerySpec 和执行引擎。用户通过中文业务名称编写查询，服务端按租户、分类及端点范围解析，内部使用稳定 ID 保存和执行。后续新增查询主题按需放在本目录，每个主题只保留一份主要说明。临时查询无需创建持久业务定义，保存查询模板及相关协议仍为候选。
