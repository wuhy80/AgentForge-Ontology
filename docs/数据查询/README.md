# 数据查询

本目录集中维护 Ontology 数据查询设计，当前仅维护文档，尚未进入编码阶段。

| 文档 | 维护内容 |
| --- | --- |
| [DataSet](DataSet.md) | 中文 Schema/属性/Link 名称编写及 ID 绑定、查询抽象、条件筛选、字段投影、关系导航、多 Link 跳转、聚合、结果与分页、预览及查询验收 |

DataSet 是查询规则的唯一主要说明；用户通过中文业务名称编写查询，服务端按租户、分类及端点范围解析，内部使用稳定 ID 保存和执行。后续新增查询主题按需放在本目录，每个主题只保留一份主要说明。临时查询无需创建持久业务定义，保存查询模板及相关协议仍为候选。

相关规则通过引用协作：

- [组织与隔离](../组织与隔离.md)：中文主名称、解析范围、歧义处理及改名后的绑定身份。
- [数据读写](../数据读写.md)：中文编辑入口与内部 ID 契约、单条/批量保存、对象与关系事务及导入。
- [Schema](../模块/Schema.md)：字段、类型、单位、计算属性、分表及查询返回描述。
- [Link](../模块/Link.md)：正反方向、关系语义、上下文、前后顺序及产线示例。
- [存储引擎](../存储引擎.md)：数据库能力、SQL 编译和存储适配。
- [性能与容量](../性能与容量.md)：查询成本、多跳工作负载、性能目标及未来测量方法。
